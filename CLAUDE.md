# Momo 学英文·国文·数学·科学 — project notes for Claude Code

Kids learning web app for a Malaysian SJKC (华小) Year 1 child, built in a claude.ai chat and
hosted on GitHub Pages: https://sclim999.github.io/kidlearning-/

## Files
- `index.html` — the whole app: HTML + CSS + vanilla JS in one file. No build step, no framework.
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png` — Add-to-Home-Screen support.
- `sw.js` — service worker for offline use (network first, cache fallback); registered only on https/localhost. Bump `CACHE` if the cached file list changes.
- `world/index.html` — a copy of github.com/SCLim999/world-explorer (3D globe, 52 countries, history, build workshop, first-person explore), opened from the 🌍 环游世界 page. To update it, copy the new `index.html` from that repo and keep the `<!-- momo-back -->` 「🐼 回 Momo」 link right after `<body class="both">`. Its own progress lives in `we_*` localStorage keys and does not earn Momo stars.
- `malware/` — a copy of github.com/SCLim999/malware-hunter (Firewall 3D, an educational first-person game about malware; index.html + css/ + js/ + DISCLAIMER.md), opened from 「更多好玩的」 → 🛡️ 病毒猎人. It costs bamboo: `openMalware()` sells a ticket (`MH_COST` 10 🎋 for `MH_MIN` 10 minutes, at most `MH_DAY` 2 a day, counted in `days[today].mh`, blocked when over the daily time limit) stored in localStorage `momo-ticket` {kid,until}. The `<!-- momo-ticket -->` guard script right after `<body class="fw">` sends the page back to Momo when there is no valid ticket, shows a countdown, and covers the game with 「时间到」 when it ends. The game's own back button (`fw-back`) points to ../index.html with label 回 Momo. Variety: `malware/js/momo-variety.js` (loaded just before `js/firewall.js`) defines `window.momoLevelHook`, which a one-line hook at the top of `loadMap()` in `js/firewall.js` calls on every level and endless run: it picks a random art style (not the 3D-glasses one, never the previous one), swaps the decorative walls (circuit, rack, code) for other computer parts (fan, RAM, disk, keyboard, cables, screen) and hue-shifts them and the floor/ceiling; doors, exit, mail terminals, vulnerabilities and the red firewall wall keep their look. Kid mode (`momo-easy`): `js/momo-variety.js` sets `window.momoEasy = true` and Chinese as the default language; `js/firewall.js` then halves virus health (bosses to 35%), makes them 35% slower with slower shots and attacks and ~45% of the damage, widens the scanner's aim (2× hit radius) and fires it faster (0.26 s), repairs integrity 4 per second after 3 s without a hit, and replaces game over with 「Momo 帮你修好了」 (back to 60). Keep all these edits (marked momo-…) when re-copying.
- `README.md` — Chinese overview for parents, with screenshots from `docs/*.png` (phone shots at 390×844 @2x, desktop at 1280×800, quantized to 256 colours to keep them small; not cached by `sw.js`).
- `fig/<name>.html` — interactive isometric "anatomy" figures (clock, magnet, plant, soil, times = 乘法积木板 on mul: tap a cube or arrow keys to pick 几排 × 每排几个, the block rises with running row totals; subtract = 双位数减法 on sub/addsub3: tens rods and ones cubes stepped through show → break a ten → take ones → take tens → answer, 8 preset problems; add = 双位数加法 on add (built from subtract.mjs): show → bring in the second number in blue → add the ones → ten ones become a green ten (进位) → add the tens → answer; divide = 除法平分 on div: a pile of cubes dealt round by round, one coloured cube per plate per round, 10 exact problems up to 20 ÷ 5) shown in an iframe under 「🔍 看看里面」 on a game's page when the game has `fig:'<name>'`. Each is generated: edit `fig/src/<name>.mjs`, then run `node fig/src/<name>.mjs` from the repo root (soil also takes `--audit`). `fig/src/page.mjs` is the shared page writer (theme follows `prefers-color-scheme`, posts its height to the app as `{momoFig,h}`); `fig/src/kit/` is a copy of the anatomy skill's kit. Add new figures to the `CORE` list in `sw.js` (it also caches `world/index.html` and the `malware/` files).

## Audience and style
- Child is SJKC Year 1. UI text is Chinese (华文). English and Malay are the target languages; Malay is called 国文 in the UI.
- Maths and Science are Chinese-medium (SJKC teaches them in Chinese), so questions are read aloud with a zh voice.
- Cute "toy block" look: thick outlined buttons with a solid bottom shadow, font Baloo 2 + PingFang SC fallbacks, panda mascot "Momo" drawn as inline SVG (`panda()`; `pandaDressed()` adds accessories).
- Colours are CSS variables on `:root` with a dark-mode set; keep all new colours as tokens.
- Must work on iPad Safari, Android Chrome and Windows Edge; big touch targets; respects `prefers-reduced-motion`.

## Data model (localStorage key `momo-learn.v1`)
`ALL = {v:2, cur, kids:{id: S}, updatedAt}`; `S` is the current child, see `blank()` for every field:
stars, bamboo (pet currency, +1 per star in `addStars`), days{YYYY-MM-DD:{stars,correct,wrong,mins,secs,rec,mc,sc,extra}},
words{"lang:topic:en":{c,w,m,iv,due,ro,rm}} (ro/rm = right/wrong answers after the word was mastered, for retention) (mastered at c>=3; then spaced review every 1/3/7/14/30 days via `due`), math{}, sci{}, cn{}, world{}, sessions[], pet{owned,wear,bg,fed,happy},
adv{done{}}, story{done{},bag[]} (彩虹岛历险记), lv{'game:level':{c,w}} (per-level game results for Momo 小老师), missions{date,done[]}, custom[{id,name,lang,words[{w,zh,e}]}] (parent's school word lists), mist{w{wordKey:ts},m{'game:level':n}} (错题本), tests[{d,s,n}] (每周小测), letterWk, settings (lang, subj, showZh, sound, goal, limit).
`ALL.lastBackup` = time of the last backup download; `ALL.pin` = optional parent PIN, stored only as `h1:salt:hash` (500 rounds of salted SHA-256 via the built-in `sha256hex`; `pinHash`/`pinOk`; plain 4-digit PINs in old saves or backups are converted in `normalize()` and written back on load). `needPin(cb)` guards settings, word-list editing and extra time.
Old saves and imported backups are upgraded in `normalize()` / `fixKid()`; keep it backward compatible.
Voice choices are per device in `momo-voice`.
In the claude.ai artifact version, `initCloud()` also syncs `ALL` via `window.claude.use('db')`; on GitHub Pages that is skipped and data stays on the device.

- Speech: Web Speech API via `speak(text, lang, queue)`; Malay falls back to Indonesian if no ms voice.

## Conventions
- Security: a `Content-Security-Policy` meta tag in `<head>` allows only this site, Google Fonts and inline code (no objects, no form posts, no base tag). Everything from storage or a backup goes through `fixKid`/`normalize` and is `esc()`-ed when shown; look-ups keyed by stored strings must use own-property checks (e.g. `isObj` for `SOBJ`). The figure `message` handler only resizes the iframe that sent it and clamps the height. All of the account's GitHub Pages projects share the `sclim999.github.io` origin, so they can read this app's localStorage.
- Keep the app a single self-contained file (the generated `fig/*.html` pages and the copied `world/` and `malware/` games are the only extra pages); no external requests besides Google Fonts.
- Every new game must record progress (`recordWord` / `recordMath`) and work with the combo, stars, cards and time-limit hooks (`overLimit()` at game start).
- Give every question a hint (`💡`) and a short child-friendly explanation after answering.
- Test with Playwright (headless Chromium): play each mode to the end and check `pageerror` is empty. Headless Chromium has a native `SpeechRecognition` that never answers: mock both `SpeechRecognition` and `webkitSpeechRecognition` to test 说说看.
