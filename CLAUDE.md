# Momo 学英文·国文·数学·科学 — project notes for Claude Code

Kids learning web app for a Malaysian SJKC (华小) Year 1 child, built in a claude.ai chat and
hosted on GitHub Pages: https://sclim999.github.io/kidlearning-/

## Files
- `index.html` — the whole app: HTML + CSS + vanilla JS in one file. No build step, no framework.
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png` — Add-to-Home-Screen support.
- `sw.js` — service worker for offline use (network first, cache fallback); registered only on https/localhost. Bump `CACHE` if the cached file list changes.
- `world/index.html` — a copy of github.com/SCLim999/world-explorer (3D globe, 52 countries, history, build workshop, first-person explore), opened from the 🌍 环游世界 page. To update it, copy the new `index.html` from that repo and keep the `<!-- momo-back -->` 「🐼 回 Momo」 link right after `<body class="both">`. Its own progress lives in `we_*` localStorage keys and does not earn Momo stars.
- `malware/` — a copy of github.com/SCLim999/malware-hunter (Firewall 3D, an educational first-person game about malware; index.html + css/ + js/ + DISCLAIMER.md), opened from 「更多好玩的」 → 🛡️ 病毒猎人. It costs bamboo: `openMalware()` sells a ticket (`MH_COST` 10 🎋 for `MH_MIN` 10 minutes, at most `MH_DAY` 2 a day, counted in `days[today].mh`, blocked when over the daily time limit) stored in localStorage `momo-ticket` {kid,until}. The `<!-- momo-ticket -->` guard script right after `<body class="fw">` sends the page back to Momo when there is no valid ticket, shows a countdown, and covers the game with 「时间到」 when it ends. The game's own back button (`fw-back`) points to ../index.html with label 回 Momo. Variety: `malware/js/momo-variety.js` (loaded just before `js/firewall.js`) defines `window.momoLevelHook`, which a one-line hook at the top of `loadMap()` in `js/firewall.js` calls on every level and endless run: it picks a random art style (not the 3D-glasses one, never the previous one), swaps the decorative walls (circuit, rack, code) for other computer parts (fan, RAM, disk, keyboard, cables, screen) and hue-shifts them and the floor/ceiling; doors, exit, mail terminals, vulnerabilities and the red firewall wall keep their look. Keep all these edits (marked momo-…) when re-copying.
- `README.md` — Chinese overview for parents.
- `fig/<name>.html` — interactive isometric "anatomy" figures (clock, magnet, plant, soil) shown in an iframe under 「🔍 看看里面」 on a game's page when the game has `fig:'<name>'`. Each is generated: edit `fig/src/<name>.mjs`, then run `node fig/src/<name>.mjs` from the repo root (soil also takes `--audit`). `fig/src/page.mjs` is the shared page writer (theme follows `prefers-color-scheme`, posts its height to the app as `{momoFig,h}`); `fig/src/kit/` is a copy of the anatomy skill's kit. Add new figures to the `CORE` list in `sw.js` (it also caches `world/index.html` and the `malware/` files).

## Audience and style
- Child is SJKC Year 1. UI text is Chinese (华文). English and Malay are the target languages; Malay is called 国文 in the UI.
- Maths and Science are Chinese-medium (SJKC teaches them in Chinese), so questions are read aloud with a zh voice.
- Cute "toy block" look: thick outlined buttons with a solid bottom shadow, font Baloo 2 + PingFang SC fallbacks, panda mascot "Momo" drawn as inline SVG (`panda()`; `pandaDressed()` adds accessories).
- Colours are CSS variables on `:root` with a dark-mode set; keep all new colours as tokens.
- Must work on iPad Safari, Android Chrome and Windows Edge; big touch targets; respects `prefers-reduced-motion`.

## Data model (localStorage key `momo-learn.v1`)
`ALL = {v:2, cur, kids:{id: S}, updatedAt}`; `S` is the current child, see `blank()` for every field:
stars, bamboo (pet currency, +1 per star in `addStars`), days{YYYY-MM-DD:{stars,correct,wrong,mins,secs,rec,mc,sc,extra}},
words{"lang:topic:en":{c,w,m,iv,due}} (mastered at c>=3; then spaced review every 1/3/7/14/30 days via `due`), math{}, sci{}, cn{}, world{}, sessions[], pet{owned,wear,bg,fed,happy},
adv{done{}}, missions{date,done[]}, custom[{id,name,lang,words[{w,zh,e}]}] (parent's school word lists), mist{w{wordKey:ts},m{'game:level':n}} (错题本), tests[{d,s,n}] (每周小测), letterWk, settings (lang, subj, showZh, sound, goal, limit).
`ALL.lastBackup` = time of the last backup download; `ALL.pin` = optional 4-digit parent PIN (`needPin(cb)` guards settings, word-list editing and extra time).
Old saves and imported backups are upgraded in `normalize()` / `fixKid()`; keep it backward compatible.
Voice choices are per device in `momo-voice`.
In the claude.ai artifact version, `initCloud()` also syncs `ALL` via `window.claude.use('db')`; on GitHub Pages that is skipped and data stays on the device.

## Where things live in index.html

(sentences in `SM44`), smcamo Camouflage, smpet Pet Show, smweather Holiday Weather p.114 (sentences in `SMX`), smprep in/on/under (sentences in `SMP`); bm13 Unit 13 Meriahnya Perayaan, `only:'ms'`; the book's own sentences, Chinese translations and word notes are in `BM13` and used by sentence mode via `w.sm`/`w.sz`; `w.note` shows on the learn card) and 46 from the family's trilingual picture dictionary marked `book:1` (months p.147 (month icons `@mon1`–`@mon12`; the days of that page are already in the Year 2 days topic), party p.5, station1/station2 (词典 37), face p.1, opp1 反义词 p.98 (+ fat/thin moved here so opp2's two "thin" never meet), opp2 反义词 (语文知识) — 5th field = English word of the opposite, `oppOf(w)`, season p.124–125 (sentences in `SEASON`), klbuild p.132–133 (Dayabumi left out: its Chinese was unreadable), school1/school2 p.22–23, land p.45, plant1/plant2 p.102–103 (5th field = habitat, see `PHAB`), fish2 p.110 (tongsan and sepat siam left out), hobby1 p.92, hobby2 p.93, tradgames p.86, costume p.85, fish, jobs1 p.87, jobs2 p.88, study1/study2 p.12–13, pharmacy p.86, ai p.176–177 (drone/dron shortened from the long printed name), robot p.178–179, sciact p.170–171, places2 p.169, seaair p.46, taste p.173 (5th field = sweet/salty/sour/bitter, see `TASTEP`), longhouse p.39, uniform p.38, police p.62, firestation p.63, sports p.90, sportgear p.34–35, hotel p.84, fruit1 p.72, fruit2 p.73, music p.135, values p.151 (no sentences), habitat p.122, urban p.164–165, materials p.172 (5th word field = property hard/soft/hot/cold, see `MATP`), idioms p.152–153 (BM simpulan bahasa, `only:'ms'`, no sentences)); words and Chinese exactly as printed; words cut off at a page edge were left out). The subject page groups them under 一年级 / 二年级 / 课本 / 图解词典 / 学校词表; the weekly quiz fallback uses Year 1 only. Every built-in word has a picture: an emoji, or `'@name'` for a hand-drawn SVG in `ICO` (about 200 icons in five blocks: calendar days, local fruits, instruments, sports gear, hotel, habitats, city, materials, idioms, taste of food, longhouse, uniformed bodies, police and fire stations, AI, robot parts, science activities, places, boats and aircraft, traditional games and costumes, freshwater fish, study room, pharmacy, hobbies, story, fish 2, in/on/under, school, trishaw, plants, face parts, antonyms, KL buildings, months, railway station, tangram shapes). Always draw word pictures with `pic(w)` (falls back to the Chinese meaning) or `ico(w)` (empty if none), never `w.e` directly.
- Custom word lists: `syncCustom()` (called in `render()`) turns `S.custom` into topics with id `my-<id>` and `only:<lang>`, appended to `TOPICS`. `BASE` = built-in topics only (album, duel, growth totals use it). Custom words may have no emoji: draw pictures with `pic(w)`, which falls back to the Chinese meaning. Word key uses `w.k||w.en`.
- Backup: `exportData()` downloads `momo-backup-YYYY-MM-DD.json` (`{app:'momo-learn',data:ALL}`); `importData()` replaces `ALL` after a confirm.
- `MODES` — word game modes: learn, listen, read, spell, dict (听写), sent, match, bubble (+ internal review/boss/math/sci). A question may carry its own `q.lang` (used by 错题本 and 小测 which mix English and BM).
- `MG` — 18 maths games: 11 Year 1 (incl. clock, story problems, calendar 日历: next/previous day and month going round, via `calQ`, `WEEKZ`, `MONZ`) and 7 Year 2 marked `yr:2` (place3 1000 以内的数, addsub3 直式加减, mul 乘法, div 除法, frac 分数, measure 长度与重量, fraclife 分一分 from the activity book: equal/unequal halves via `splitSvg`, food (`FOODS`) cut into 2 or 4 equal parts; helpers `nearOpts`, `blocks`, `colCalc`, `fracSvg`, `rulerSvg`), grouped under 一年级/二年级 by `mathCards()`; the weekly quiz uses Year 1 maths only. `SG` — 16 science games: 8 Year 1 (incl. soil) and 4 Year 2 marked `yr:2` (人类的成长 grow, 动物的成长 agrow, 植物的成长 pgrow, 光与影子 light; built with the `qPick`/`qNext` helpers), plus two Year 1 games from the dictionary: habitat 动物住在哪里 (`HABH` habitats, `HABA` animals with habitats never offered as wrong answers) and matprop 硬、软、热、冷 (uses the materials topic) and taste 甜、咸、酸、苦 (uses the taste topic) and phabitat 植物长在哪里 (plant1/plant2 words with `PHAB` habitats), shown under separate 一年级/二年级 headings by `sciCards()`; the weekly quiz uses Year 1 science only, `CG` — 9 华文 games: 3 Year 1 on `HZ` (41 characters) plus xinyang 我们的宗教信仰 (from the 我的宗教信仰 textbook page: place of worship ↔ religion, and the page's sentences incl. 稻神/神灵) plus fanyi 反义词 (Year 1; opp1/opp2 words, level 1 in 华文, level 2 in English/BM, never offers a second correct opposite) and 4 Year 2 (`yr:2`: kanzi2, tingzi2, pinyin2 on `HZ2` (34 characters), and ciyu 词语 on `CI2`, a de-duplicated list of two-character words). `GKIND(g)`/`GAME(g)` look a game up across all three; `isMG(mode)` is true for math/sci/cn. Each has `gen(level)` returning `{title, say, html(hint), opts[{v,l}], ans, explain, sayAns}`; they all run on the shared engine (`startMath`, `vMath`, `answer`).
  No repeats: rounds are built with `genSet(game,level,n,key)` (also used by bosses and 错题本), which takes the least-recently-seen of 60 candidates per slot using `qSig(q)` (wording + answer + picture/options without emoji) and an in-memory `RECENT` history, so a round has no repeats when the bank is big enough, unavoidable repeats are never back-to-back, and the next round avoids what was just asked. Duel and the weekly quiz de-duplicate their own picks. Stage questions (`qNext`) ask both 「下一个」 and 「前面」.
  Levels (`LVN`): 1 容易, 2 中等, 3 困难. 困难 = 10 questions, no 💡 button; a game with its own `l3` label has real level-3 content in `gen(3)`, the others get a mix of level 1 and 2 via `genL()`.
- 🌍 环游世界: `WX` wraps data copied from world-explorer (`flagSVG`, `COUNTRIES` with capitals/facts/greetings, `EXTRA` landmark/animal/flower, `ANIMALS`); `WG` = 6 games on the shared engine (wflag, wcap, wanimal, wland, whello, wcont), kind `world`, progress in `S.world`. It is an extra subject in `SUBJS` (`extra:true`, not a petal), reached from 「更多好玩的」 (`data-act="world"`); its subject page also links to `world/index.html`. `whello` only asks greetings unique to one country (`HI_UNIQ`). `mytour` 马来西亚旅游胜地 (dictionary p.98: 9 places in `MYTOUR`, states in `MYST`) asks place → state and state → place. `wflag2` 全世界国旗 uses `WF` (197 countries from the family's world-flag poster, by continent; parsed from `WF_RAW`) drawn as emoji flags via `flagEmoji(id)`; it is hidden when `flagEmojiOK()` says the device can't draw flag emoji (Windows), and look-alike flags (`WF_SAME`, e.g. Indonesia/Monaco) never share a question.
- `SHOP`, `BGS` — Momo pet items; `STATIONS`, `REGIONS` — adventure map (20 stations incl. 4 bosses); `MISSIONS` — daily real-life tasks; duel = `D`, `startDuel`, `vDuel`. `startMist`/`vMist` (错题本), `startTest`/`vTest` (每周小测), `vPrint` (printable sticker chart, `@media print`), `maybeLetter`/`showLetter` (Momo's weekly letter), `startSay` (speech-recognition check in learn mode).
- Home (`vHome`) is a big subject picker drawn as a hibiscus 大红花 (`flower()`: one SVG petal per subject in `SUBJS` order en, ms, math, sci, cn → `data-act="pick"`, Momo in the centre → pet; petals are `role=button` `<g>` elements made keyboard-operable in the `keydown` handler; colours `--hib*`, `--stamen`) plus a small "更多好玩的" feature grid; `vSubject` shows the chosen subject's topics/games (`curSubj()`), and topic pages go back to it with `data-act="subjpage"`.
- Parent dashboard 家长后台 (`vAdmin`, opened via `openAdmin()` from settings; always PIN-protected, asks to set a PIN first): per-kid totals, subject accuracy, strengths/weaknesses (`adminStats`, items with ≥6 answers), interests from `sessions` (subject share, favourite modes, time of day), 6-week trend, hardest words; `adminText` copies a summary. Sessions keep the last 300 entries with `sec` duration; duels are recorded too.
- Per-round look: every game start (`startGame`, `startMath`, `startBoss`, `startMist`, `startTest`, `startDuel`) calls `newLook()`, which picks a scene from `SCENES` (9: ocean, space, forest, candy, farm, garden, city, toys, fruit — background tint `--scene-tint` via `html[data-scene]`, floating decorations in `#scenedeco`, and the counting objects copied into `OBJ`) and a random art style from `SKINS` (except the busy 'glass'), never the same as the previous round. `render()` applies `LOOK.skin` only in game/end/duel views, so the child's own skin returns afterwards. `S.autoLook=false` (settings 「游戏画风」) turns it off and restores `OBJ0`.
- Views are template-string functions (`vHome`, `vSubject`, `vAdmin`, `vTopic`, `vGame`, `vGrowth`, `vPet`, `vMap`, `vAlbum`, `vMissions`, `vDuel`, `vSettings`…) chosen in `render()`.
- All clicks go through one delegated handler: `data-act` + `data-v` → `switch(a)` at the bottom.
- Speech: Web Speech API via `speak(text, lang, queue)`; Malay falls back to Indonesian if no ms voice.

## Conventions
- Keep the app a single self-contained file (the generated `fig/*.html` pages and the copied `world/` and `malware/` games are the only extra pages); no external requests besides Google Fonts.
- Every new game must record progress (`recordWord` / `recordMath`) and work with the combo, stars, cards and time-limit hooks (`overLimit()` at game start).
- Give every question a hint (`💡`) and a short child-friendly explanation after answering.
- Test with Playwright (headless Chromium): play each mode to the end and check `pageerror` is empty. Headless Chromium has a native `SpeechRecognition` that never answers: mock both `SpeechRecognition` and `webkitSpeechRecognition` to test 说说看.
